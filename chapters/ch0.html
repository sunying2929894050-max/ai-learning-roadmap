函数：def / return

ch4 的 answer_question()、ch5 的 chunk_text()、ch7 的 judge_answer()——项目全程用函数组织代码。

# 定义函数：def 函数名(参数):
def greet(name):
    message = f"你好，{name}！"
    return message              # return 把结果"返回"给调用者

result = greet("小明")
print(result)   # 你好，小明！

# 带默认参数（ch5 chunk_text 用到）
def chunk_text(text, size=400, overlap=80):
    chunks = []
    start = 0
    while start < len(text):
        end = start + size
        chunks.append(text[start:end])
        start += size - overlap
    return chunks

# 返回多个值（用括号包起来是元组）
def get_info():
    return "张三", 25   # 返回两个值

name, age = get_info()  # 解包接收
项目用法：ch7 里 answer, context = rag_answer_with_context(question) 就是接收函数返回的两个值。

列表 + for 循环

ch5 的文档片段是列表；ch7 的评估集是列表；ch6 的 Agent 消息历史也是列表。

# 列表：用方括号，可以放任何东西
chunks = ["片段一内容", "片段二内容", "片段三内容"]
questions = ["年假多少天？", "报销截止时间？"]

# 访问元素（从 0 开始）
print(chunks[0])      # "片段一内容"
print(chunks[-1])     # "片段三内容"（最后一个）

# 常用操作
chunks.append("新片段")     # 末尾加一个
len(chunks)                 # 长度
chunks[0:2]                 # 切片，取前两个

# for 循环（遍历列表）
for item in EVAL_SET:       # ch7 里这样循环评估集
    print(item["question"])

# 列表推导式（常见的简洁写法）
scores = [r["score"] for r in results]        # 从每个结果里取 score
found = [kw for kw in keywords if kw in text] # ch7 关键词检查就是这个

# join：把列表合成一个字符串（ch5 里把检索片段拼成 context）
context = "\n\n".join(chunks)   # 用两个换行分隔，合成一段长文本
项目用法：ch7 里 context = "\n\n".join(results["documents"][0]) 就是把检索到的片段列表合并成一段 context。

字典 + JSON

API 请求和响应都是 JSON；ch6 的 Agent 工具调用结果也是 JSON；ch7 的评估报告用 JSON 保存。

import json   # 内置库，不需要 pip install

# 字典：键值对，用花括号
eval_item = {
    "id": "e1",
    "question": "年假多少天？",
    "expected_keywords": ["10天", "15天"],
}

# 访问和修改
print(eval_item["question"])        # "年假多少天？"
eval_item["answer"] = "满一年10天"  # 新增字段

# 字典 → JSON 字符串（写入文件前）
json_str = json.dumps(eval_item, ensure_ascii=False, indent=2)
print(json_str)
# {
#   "id": "e1",
#   "question": "年假多少天？",
#   ...
# }

# JSON 字符串 → 字典（API 返回的响应解析）
parsed = json.loads(json_str)
print(parsed["id"])   # "e1"

# 遍历字典
for key, value in eval_item.items():
    print(f"{key}: {value}")
项目用法：ch6 Agent 里，模型输出 {"thought":"...","action":"calculator","input":"3*12"}，你用 json.loads() 解析后取 parsed["action"] 决定调哪个工具。

文件读写

ch4 要读取 ch3 的 prompt 模板文件；ch5 要读取公司文档；ch7 要把评估报告写成 JSON 文件。

import json

# 读取文本文件（ch4 读 prompt 模板）
with open("ch3-qa-prompt.txt") as f:
    template = f.read()          # 整个文件内容作为一个字符串
print(template[:50])             # 看前 50 个字符

# 写入文本文件
with open("output.txt", "w", encoding="utf-8") as f:
    f.write("写入的内容")

# 读取 JSON 文件
with open("data.json", encoding="utf-8") as f:
    data = json.load(f)          # 直接解析成 Python 字典/列表

# 写入 JSON 文件（ch7 保存评估报告）
results = [{"id": "e1", "score": 8}, {"id": "e2", "score": 9}]
with open("eval_report.json", "w", encoding="utf-8") as f:
    json.dump(results, f, ensure_ascii=False, indent=2)
# 写完后可以用任何文本编辑器打开 eval_report.json 查看
with open 是什么：这是 Python 的上下文管理器，自动处理文件打开和关闭——你只需要写 with 块里的逻辑，不用手动 close()。

环境变量：安全存 API key

ch4 开始每个项目文件都要读取 API key——正确做法是用环境变量，绝对不要把 key 写进代码。

import os

# 在终端里设置（每次新开终端都需要重设）
# Mac / Linux：
# export DEEPSEEK_API_KEY="sk-你的key"
# Windows（cmd）：
# set DEEPSEEK_API_KEY=sk-你的key

# Python 代码里读取
api_key = os.environ["DEEPSEEK_API_KEY"]     # 如果变量不存在会报错
api_key = os.environ.get("DEEPSEEK_API_KEY") # 不存在时返回 None，不报错

# 实战：ch4 的正确写法
from openai import OpenAI
client = OpenAI(
    api_key=os.environ["DEEPSEEK_API_KEY"],  # ✓ 从环境变量读
    # api_key="sk-xxx",                      # ✗ 绝对不要这样写！
)
永久保存环境变量的方法：每次关终端就失效的问题，可以把 export DEEPSEEK_API_KEY="sk-..." 加进 ~/.zshrc（Mac）或 ~/.bashrc（Linux）的末尾，然后 source ~/.zshrc 重新加载。
更方便：创建项目目录下的 .env 文件写入 DEEPSEEK_API_KEY=sk-xxx，用 pip install python-dotenv 后在代码最开头加 from dotenv import load_dotenv; load_dotenv()。记住把 .env 加进 .gitignore！

综合实战：能跑 ch4 的代码了

学完上面 8 节，你已经能读懂并跑通 ch4 的项目代码。来对照一下：

import os               # ← S7：环境变量
from openai import OpenAI  # ← S8：pip install openai 后导入

client = OpenAI(
    api_key=os.environ["DEEPSEEK_API_KEY"],  # ← S7：读环境变量
    base_url="https://api.deepseek.com",
)

with open("ch3-qa-prompt.txt") as f:  # ← S6：文件读写
    template = f.read()

def answer_question(document_content, user_question):  # ← S3：函数
    prompt = template.replace("{document_content}", document_content)  # ← S2：字符串 replace
    prompt = prompt.replace("{user_question}", user_question)

    response = client.chat.completions.create(
        model="deepseek-chat",
        messages=[{"role": "user", "content": prompt}],  # ← S5：字典
        max_tokens=512,
    )
    return response.choices[0].message.content  # ← S3：return

# 调用函数
doc = "TechCorp 年假政策：满一年10天，满三年15天。"
answer = answer_question(doc, "年假多少天？")
print(answer)  # ← S1：print
每一行你都看懂了。现在回去 ch4，把 API key 设好，跑 python3 project/ch4-api-client.py。
