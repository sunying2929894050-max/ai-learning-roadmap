新手扫雷

吴恩达课假设你已经理解以下概念——但新手往往没见过。在进课之前把这些读一遍，遇到对应内容时就不会懵。

🚧
向量化（Vectorization）是什么

课里代码经常写 np.dot(w, x) 而不是 for i in range(n): total += w[i]*x[i]。不是为了炫技——NumPy 矩阵运算底层是 C，比 Python 循环快 100 倍。你看到"向量化实现"，就是"用 NumPy 数组运算代替 for 循环"。遇到 .dot()、@、np.sum(axis=...) 看不懂，先去 ch21 → NumPy Quickstart 补一补。

🚧
损失函数（Loss Function）是什么

直白讲：就是一把尺子，量"模型预测值离正确答案有多远"。读数越大说明预测越差，读数越小说明越准。训练 = 让这把尺子的读数不断变小。常见的两把尺子：MSE（均方误差，用于预测连续数字，如房价）、交叉熵（用于预测类别，如垃圾邮件/正常邮件）。

🚧
梯度下降的直觉

想象你蒙着眼站在一座山上，目标是走到谷底（损失最小）。策略：用脚感受地面坡度（梯度），往下坡方向走一小步（学习率），重复。梯度 = 当前这个点，哪个方向最陡。学习率控制每步多大：太大容易迈过谷底来回震荡；太小要走很久才到。这就是模型"学习"的全部机制。

🚧
"特征（Feature）"和"标签（Label）"

Feature 是喂给模型的输入信息（如：房子面积、楼层、地段）。Label 是你想预测的正确答案（如：房价）。训练集里两者都有；预测时你只有 Feature，模型给出 Label。几乎所有 ML 代码都是 X（特征矩阵）和 y（标签向量），认识这两个字母就能读懂大多数代码框架。

🚧
训练集 / 验证集 / 测试集——为什么要拆三份

模型在训练数据上调出的好成绩，可能只是"背了这批题的答案"——换新题就露馅，这叫过拟合。解决：把数据拆成三份：训练集（用来训练）、验证集（训练过程中调超参数）、测试集（最后评估真实水平，只用一次）。如果你在测试集上反复调参，它就变成了验证集，你就没有真正的"新题"可以检验了。
