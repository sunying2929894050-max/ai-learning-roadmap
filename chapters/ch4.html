②

大模型 API 调用

不必自己训练大模型。通过 API 调用已有的大模型（Claude、GPT 等），是绝大多数 AI 应用的实际做法。

▸ 基础 API 调用结构
import anthropic  # pip install anthropic

client = anthropic.Anthropic(api_key="your_api_key")

message = client.messages.create(
    model="claude-opus-4-8",
    max_tokens=1024,
    system="你是一位专业的数据分析师，用简洁清晰的语言回答问题。",
    messages=[
        {"role": "user", "content": "请分析这组销售数据的趋势：[100, 120, 115, 140, 165, 180]"}
    ]
)

print(message.content[0].text)
▸ 结构化输出（让 AI 返回可解析的 JSON）
import json

prompt = """分析以下产品评论，返回 JSON 格式：
{"sentiment": "正面/负面/中性", "score": 1-5, "key_issues": ["问题1", "问题2"]}

评论：这款耳机音质不错，但佩戴三小时后耳朵有些不舒服，包装也比较简陋。"""

response = client.messages.create(
    model="claude-opus-4-8",
    max_tokens=512,
    messages=[{"role": "user", "content": prompt}]
)

result = json.loads(response.content[0].text)
print(result["sentiment"])     # 中性
print(result["key_issues"])    # ["佩戴舒适度", "包装质量"]
API 调用的核心经济学：大模型按 token 计费（输入 + 输出）。好的提示词不只是为了效果，也是为了效率——清晰简洁的提示词减少 token 消耗，降低成本。
