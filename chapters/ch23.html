深度学习与 PyTorch

神经网络、反向传播、PyTorch——指路最好的入门资源，并提前清掉新手在 d2l/吴恩达 DL 课里最容易卡住的六个概念。

本节定位

深度学习是训练路线的核心——神经网络、反向传播、PyTorch，以及 CNN / Transformer 的原理。这章不重新讲一遍，而是帮你找到最好的入门资源，并提前清掉"你以为懂了其实卡在概念上"的地雷。

前置：Python（能写类和函数）+ NumPy（矩阵运算）+ 机器学习基础（ch22，至少看完吴恩达 ML 第1门）。没有这些基础直接来学深度学习，会卡在每一个知识点上。

②

新手扫雷

以下六个概念，d2l 和吴恩达 DL 课默认你已经懂——但新手通常第一次遇到会完全懵。在进课之前读一遍，遇到对应内容时就能直接理解。

🚧
张量（Tensor）和 NumPy 数组的区别

PyTorch 里到处是 torch.Tensor，和 NumPy 的 ndarray 几乎是同一个东西（都是多维数组），但 Tensor 额外支持两件事：① 可以运行在 GPU 上（.cuda() 或 .to("cuda")）；② 自动记录计算过程，能反向求梯度（requires_grad=True）。如果你已经会 NumPy，Tensor 的大多数操作一一对应，遇到不认识的 API 直接搜 PyTorch 文档。

🚧
为什么要 GPU

神经网络训练的核心运算是矩阵乘法，GPU 有数千个并行计算核心，专门干这个。CPU 是串行的，跑同样的矩阵运算可能慢几十到上百倍。没有 GPU 也能入门——在 CPU 上跑小模型够学概念，Google Colab 提供免费 GPU 够跑 MNIST / 小型 NLP 实验。入门阶段不需要买卡。

🚧
反向传播（Backprop）的直觉

新手听到"反向传播"以为很复杂。直白讲：用链式法则，从最终损失出发，一层层往回算"每个参数对损失的责任有多大"（偏导数）。类比：一道菜咸了，追溯是哪个环节加盐加多了——反向传播就是这个追溯过程，只是数学版的。PyTorch 的 .backward() 帮你自动算，你不需要手推公式；但理解"它在追溯什么"让你看到错误时不会完全懵。

🚧
Batch（批次）是什么

训练时不是一张图一张图送进模型，而是一次送一批（如64张），算一次平均梯度，更新一次参数——这叫 mini-batch 梯度下降。Batch size（批大小）是超参数：太大显存撑不住，太小梯度噪声大（但有一定正则化效果）。d2l 和所有 PyTorch 代码里大量出现的 for X_batch, y_batch in dataloader:，就是在遍历每个 batch。

🚧
过拟合 / 正则化 在深度学习里的样子

从 ch22 你已经知道过拟合（训练好测试差）。深度学习里更常见也更严重——网络参数动辄百万。遇到"训练 loss 很低但 val loss 很高"，就是过拟合了。常用对策：Dropout（训练时随机关闭一些神经元，防止依赖特定路径）、Early Stopping（验证集误差开始升高就停止训练）、权重衰减（L2 正则化）、减少网络层数/宽度。

BatchNorm 经常一起被提到，但它不是过拟合对策——它的主职是让训练更稳、更快：稳定每层输入的数值分布，允许使用更大学习率，缓解梯度消失。有一点附带的正则化副作用，但不能靠它治过拟合。新手容易把它和 Dropout 混为一谈。

🚧
一个完整训练循环长什么样

d2l 和所有 PyTorch 教程都有这个标准模板，但新手第一次看到六七行不知道为什么是这个顺序：

optimizer.zero_grad()   # ① 清上一步残留的梯度（PyTorch 默认累加，不清会出错）
output = model(X)        # ② 前向传播：算预测值
loss = criterion(output, y) # ③ 算损失（预测离正确答案多远）
loss.backward()         # ④ 反向传播：算每个参数的梯度
optimizer.step()        # ⑤ 用梯度更新参数

这五行是神经网络学习的一次心跳，顺序不能错。看任何 PyTorch 训练代码，先找这五行，其余的都是数据加载和日志打印。
