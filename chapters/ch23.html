神经网络基础：从感知机到深度网络

神经网络的灵感来自人脑，但实际上是纯数学结构——多层矩阵乘法 + 非线性激活函数的组合。

①
单个神经元 = 加权求和 + 激活函数

每个神经元接收多个输入，对每个输入乘以一个权重，求和后加偏置，再经过激活函数输出。

输出 = f( w₁x₁ + w₂x₂ + ... + wₙxₙ + b )
其中 f 是激活函数（如 ReLU = max(0, x)）
②
为什么需要激活函数？

没有激活函数，多层线性变换叠加等价于单层线性变换，无论多少层都没用。激活函数引入非线性，让网络能拟合任意复杂的函数。

常用激活函数：
ReLU: f(x) = max(0, x)——最常用，计算简单，解决梯度消失
Sigmoid: f(x) = 1/(1+e⁻ˣ)——输出 0~1，用于二分类输出层
Softmax: 多分类输出层，输出各类别概率之和为 1
③
深度网络 = 多层堆叠

输入层 → 隐藏层₁ → 隐藏层₂ → ... → 输出层。"深度"就是指多个隐藏层。层数越多，能表达的函数越复杂，但也越难训练（梯度消失问题）。

类比：特征抽象层级
图像识别时：第一层检测边缘和纹理 → 第二层组合成形状（圆、角）→ 第三层组合成部件（眼睛、耳朵）→ 输出层判断"这是一只猫"。深度的价值就在这里。
②

PyTorch 核心：张量、自动求导、训练循环

PyTorch 是目前研究和工业界最流行的深度学习框架。核心优势：动态计算图（易调试）+ Pythonic API（代码直观）。

▸ 张量（Tensor）= 支持 GPU 加速的 NumPy 数组
import torch

# 创建张量
x = torch.tensor([[1.0, 2.0], [3.0, 4.0]])
print(x.shape)   # torch.Size([2, 2])
print(x.dtype)   # torch.float32

# 矩阵运算
y = torch.zeros(2, 3)
z = x @ torch.ones(2, 3)   # 矩阵乘法

# GPU 加速（有 CUDA 时）
if torch.cuda.is_available():
    x = x.cuda()   # 迁移到 GPU
▸ 自动求导（Autograd）= 自动计算梯度
x = torch.tensor(3.0, requires_grad=True)   # 跟踪梯度
y = x ** 2 + 2 * x + 1                       # y = x² + 2x + 1
y.backward()                                   # 反向传播
print(x.grad)   # dy/dx = 2x+2 → 在 x=3 时 = 8.0
Autograd 是 PyTorch 的核心魔法：你只需写出前向计算（y如何从x得到），.backward() 会自动追溯链式法则，计算出所有参数的梯度。
▸ 完整训练循环
import torch
import torch.nn as nn

# 1. 定义模型（全连接网络，2输入→4隐藏→1输出）
model = nn.Sequential(
    nn.Linear(2, 4),
    nn.ReLU(),
    nn.Linear(4, 1),
    nn.Sigmoid()
)

# 2. 损失函数 + 优化器
criterion = nn.BCELoss()                            # 二分类交叉熵
optimizer = torch.optim.Adam(model.parameters(), lr=0.01)

# 3. 训练循环（标准模板）
for epoch in range(100):
    optimizer.zero_grad()   # 清除上一步的梯度（必须！）
    outputs = model(X_train)
    loss = criterion(outputs, y_train)
    loss.backward()         # 反向传播，计算梯度
    optimizer.step()        # 更新参数

    if epoch % 20 == 0:
        print(f"Epoch {epoch}: loss={loss.item():.4f}")
③

卷积神经网络（CNN）：图像的专用架构

传统全连接网络处理图像时，100×100 像素的图片有 10000 个输入，第一层就有几百万个参数——太多了。CNN 用"局部连接 + 权重共享"解决这个问题。

①
卷积层（Conv Layer）

用一个小的滑动窗口（卷积核/Filter）在图像上滑动，每个位置做点积，提取局部特征（边缘、纹理）。多个不同的卷积核提取多种特征，输出"特征图（Feature Map）"。

类比：用不同的放大镜分别看"横线"、"竖线"、"斜线"——每种放大镜是一个卷积核。
②
池化层（Pooling Layer）

对特征图进行下采样（如 Max Pooling 取每个 2×2 区域的最大值），减少参数量，保留最显著的特征，增强位置不变性。

③
全连接层（FC Layer）

卷积层提取的特征展平后，接入全连接层做最终分类。

import torch.nn as nn

class SimpleCNN(nn.Module):
    def __init__(self):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(1, 32, kernel_size=3, padding=1),  # 卷积层（灰度图输入）
            nn.ReLU(),
            nn.MaxPool2d(2),                              # 池化层：尺寸减半
            nn.Conv2d(32, 64, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2),
        )
        self.classifier = nn.Sequential(
            nn.Flatten(),
            nn.Linear(64 * 7 * 7, 128),                  # 28×28 图像经过两次池化 → 7×7
            nn.ReLU(),
            nn.Linear(128, 10)                            # 10分类（如 MNIST 手写数字）
        )

    def forward(self, x):
        return self.classifier(self.features(x))

model = SimpleCNN()
print(f"模型参数量: {sum(p.numel() for p in model.parameters()):,}")
CNN 里程碑：2012 年 AlexNet 在 ImageNet 竞赛上准确率大幅领先传统方法，开启深度学习时代。VGG、ResNet、EfficientNet 是后续经典架构，ResNet 引入"残差连接"解决了深层网络的梯度消失问题。
④

Transformer 与自然语言处理（NLP）

从 RNN 到 Transformer，是 NLP 领域最重要的架构演进。ChatGPT、BERT 都基于 Transformer。

◆ RNN（循环神经网络）的局限

RNN 逐字处理文本，每一步把当前词和"记忆（hidden state）"一起处理。但长序列时早期词的信息会逐渐"遗忘"（梯度消失），且无法并行计算（必须一步步来）。

类比：短期记忆 vs 全局视角
RNN 像一个人一边读文章一边记笔记，读到第 500 个词时可能已经忘了第 1 个词的内容。Transformer 则像同时能看到整篇文章，每个词可以直接"关注"任何其他词。
◆ Transformer 的核心：自注意力机制（Self-Attention）

对于输入序列的每个词，计算它与序列中所有其他词的"相关性分数"（注意力权重），加权求和，得到该词的新表示。让模型能捕捉长距离依赖关系。

例子："The animal didn't cross the street because it was too tired."
"it" 指代什么？人类看上下文就知道是"animal"，不是"street"。
自注意力让模型在处理"it"时，自动对"animal"赋予高权重——捕捉到了这种跨越多词的依赖关系。RNN 在长句中常常做不到这一点。
特性RNNTransformer
并行计算❌ 只能顺序处理✅ 所有位置同时计算
长距离依赖⚠️ 容易遗忘早期信息✅ 每个词直接关注任意位置
训练速度慢快（GPU 利用率高）
代表模型LSTM、GRUBERT、GPT、T5

⑤

迁移学习：站在巨人肩膀上

从头训练大模型需要海量数据和大量计算资源。迁移学习：借用已经在大规模数据上训练好的模型，在自己的小数据集上微调，花很少代价获得很好效果。

①
预训练（Pre-training）

在海量通用数据上训练，让模型学到通用特征。ImageNet（1400万图片）上训练的 ResNet，学到了识别边缘、纹理、形状等通用视觉特征。GPT-3 在万亿词上训练，学到了语言的通用规律。

②
微调（Fine-tuning）

冻结预训练模型的大部分层，只训练最后几层（或全部层用极小学习率）。你的任务数据（可以很少）引导模型把通用特征适配到特定任务。

import torchvision.models as models

# 加载 ImageNet 预训练的 ResNet-18
model = models.resnet18(pretrained=True)

# 替换最后一层，适配你的任务（如识别3种花）
model.fc = nn.Linear(model.fc.in_features, 3)

# 只训练最后一层（冻结前面的层）
for param in model.parameters():
    param.requires_grad = False
model.fc.requires_grad_(True)
类比：专科培训
一个医学博士（预训练模型）已经掌握了解剖学、生理学等通用知识。让他去做皮肤科（特定任务），只需要几个月的专科培训（微调），而不是从头读 8 年医学院（从头训练）。

实战：MNIST 手写数字识别（完整 PyTorch 代码）

MNIST 是深度学习的"Hello World"——识别手写的 0-9 数字（28×28 像素灰度图）。

import torch
import torch.nn as nn
import torch.optim as optim
from torchvision import datasets, transforms
from torch.utils.data import DataLoader

# ① 数据加载 + 预处理
transform = transforms.Compose([
    transforms.ToTensor(),
    transforms.Normalize((0.1307,), (0.3081,))  # MNIST 的均值和标准差
])
train_data = datasets.MNIST('./data', train=True,  download=True, transform=transform)
test_data  = datasets.MNIST('./data', train=False, download=True, transform=transform)
train_loader = DataLoader(train_data, batch_size=64, shuffle=True)
test_loader  = DataLoader(test_data,  batch_size=64)

# ② 定义模型（简单全连接网络）
model = nn.Sequential(
    nn.Flatten(),
    nn.Linear(28*28, 256), nn.ReLU(),
    nn.Dropout(0.3),         # Dropout 防止过拟合
    nn.Linear(256, 128),     nn.ReLU(),
    nn.Linear(128, 10)       # 10个数字类别
)

# ③ 训练
optimizer = optim.Adam(model.parameters(), lr=0.001)
criterion = nn.CrossEntropyLoss()

for epoch in range(5):
    model.train()
    for X_batch, y_batch in train_loader:
        optimizer.zero_grad()
        loss = criterion(model(X_batch), y_batch)
        loss.backward()
        optimizer.step()

    # ④ 每轮评估
    model.eval()
    correct = 0
    with torch.no_grad():
        for X_batch, y_batch in test_loader:
            correct += (model(X_batch).argmax(1) == y_batch).sum().item()
    print(f"Epoch {epoch+1}: 测试集准确率 {correct/len(test_data):.3f}")
动手练习：① 在 nn.Sequential 里把全连接层换成 SimpleCNN（上一节代码），对比准确率提升。② 把 Dropout(0.3) 改成 0.8，观察过拟合现象。③ 把 epoch 从 5 改成 1，观察训练不足的影响。

本章小结

第四章核心要点
  • 神经元 = 加权求和 + 激活函数；激活函数引入非线性，让多层网络能拟合任意复杂函数；深度 = 多层隐藏层，每层学习越来越抽象的特征。
  • PyTorch 核心：Tensor（支持 GPU 的数组）+ Autograd（自动计算梯度）+ 标准训练循环（zero_grad → forward → loss → backward → step）。
  • CNN 通过局部连接 + 权重共享大幅减少参数，擅长提取图像的空间特征（边缘→形状→部件→物体），是图像任务的标准架构。
  • Transformer 的自注意力机制让每个词直接关注序列中任意其他词，解决了 RNN 的长距离依赖问题，且支持并行计算——ChatGPT、BERT 都基于此架构。
  • 迁移学习：用预训练模型（ImageNet/GPT）的通用特征，在少量自有数据上微调，以极低成本适配特定任务。是实际项目的首选策略。
  • 训练深度学习模型的关键超参数：学习率、batch size、epoch 数、网络深度/宽度、Dropout 比例。调参是核心技能。
  • ResNet 的残差连接解决了深层网络的梯度消失问题；Dropout 通过随机关闭神经元防止过拟合；BatchNorm 稳定训练过程。
⑨

词汇表

激活函数（Activation Function）
神经元输出前经过的非线性变换。ReLU（max(0,x)）是最常用的；Sigmoid 用于二分类输出；Softmax 用于多分类输出。
卷积核（Kernel / Filter）
CNN 中在图像上滑动的小矩阵（如 3×3），提取局部特征。同一卷积核的权重在所有位置共享，大幅减少参数量。
池化（Pooling）
对特征图进行下采样（如取 2×2 区域的最大值），减少参数量，保留显著特征，增强位置不变性。
自注意力（Self-Attention）
Transformer 的核心机制。让每个词计算与序列中所有其他词的相关性，加权求和得到新表示。解决长距离依赖问题。
Dropout
训练时随机关闭一定比例的神经元，防止模型对特定神经元过度依赖。推理时恢复所有神经元，是常用正则化技术。
迁移学习（Transfer Learning）
把在大规模数据上预训练好的模型，迁移到新的相关任务上。通过微调少量层，以低成本适配特定任务。
微调（Fine-tuning）
在预训练模型的基础上，用任务特定的小数据集继续训练，让通用特征适配到特定任务。
批大小（Batch Size）
每次梯度更新使用的样本数量。大 batch 训练稳定但可能陷入局部最优；小 batch 噪声大但正则化效果好。
残差连接（Residual Connection）
ResNet 提出的技术：把输入直接加到某几层后的输出上（跨层连接）。解决了深层网络的梯度消失问题，让训练数百层的网络成为可能。
特征图（Feature Map）
卷积层的输出，每个卷积核产生一个特征图，表示图像在该卷积核捕捉的特征（如横线、竖线）的响应强度。
