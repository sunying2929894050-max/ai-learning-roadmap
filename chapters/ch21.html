Python 基础语法

Python 是 AI / 机器学习领域使用最广泛的语言。语法接近自然语言，入门门槛低。

▸ 变量与基本类型
name = "Alice"          # 字符串 str
age  = 20               # 整数 int
score = 95.5            # 浮点数 float
is_student = True       # 布尔 bool

print(f"{name} 的分数是 {score}")   # 输出: Alice 的分数是 95.5
▸ 条件与循环
# 条件
if score >= 90:
    print("优秀")
elif score >= 60:
    print("及格")
else:
    print("不及格")

# 列表与循环
grades = [85, 92, 78, 96, 60]
total = 0
for g in grades:
    total += g
average = total / len(grades)
print(f"平均分: {average}")   # 输出: 平均分: 82.2
▸ 函数
def predict_pass(score, threshold=60):
    """判断是否及格，默认及格线 60 分"""
    return score >= threshold

print(predict_pass(75))     # True
print(predict_pass(55))     # False
print(predict_pass(55, 50)) # True（自定义及格线）
核心心法
写 AI 代码时打交道最多的四样东西：列表（存数据）、字典（存键值对配置）、函数（封装逻辑）、循环（批量处理）。掌握这四样，80% 的 AI 入门代码都能读懂。
▸ 字典与列表推导式
# 字典：存储键值对
student = {"name": "Bob", "score": 88, "passed": True}
print(student["name"])   # Bob

# 列表推导式：一行完成转换（AI 代码里很常见）
raw_scores = [85, 92, 78, 96, 60]
normalized = [(s - 60) / 40 for s in raw_scores]  # 归一化到 0~1
print(normalized)  # [0.625, 0.8, 0.45, 0.9, 0.0]

数据科学三件套：NumPy / Pandas / Matplotlib

① NumPy — 高速矩阵运算

NumPy 的核心是 ndarray（多维数组）。它比 Python 原生列表快 100 倍以上，因为底层用 C 实现，支持向量化运算——一行代码处理整列数据，不用写循环。

import numpy as np

a = np.array([1, 2, 3, 4, 5])
b = np.array([10, 20, 30, 40, 50])

print(a * 2)       # [ 2  4  6  8 10]  — 广播运算，不用循环
print(a + b)       # [11 22 33 44 55]
print(np.mean(a))  # 3.0
print(np.std(a))   # 1.414...

# 矩阵（机器学习的核心数据结构）
M = np.array([[1, 2], [3, 4], [5, 6]])  # 3行2列矩阵
print(M.shape)  # (3, 2)
print(M.T)      # 转置 → 2行3列
为什么机器学习必须用 NumPy：一个有 1000 个特征的数据集，每行是一个长度 1000 的向量。模型每次预测需要矩阵乘法。NumPy 让这些运算既简洁又快速。

Pandas 的核心是 DataFrame（数据框），就是一张有行列标签的表格，相当于 Python 里的 Excel。

# 或：df2.fillna(df2.mean())  # 用均值填充空值

④

线性代数：向量与矩阵

机器学习中所有的数据和参数都用向量或矩阵表示。不理解这一点，很难真正理解模型在做什么。

①
向量（Vector）= 单个样本的特征表示

一组有序的数字。例如一个学生的特征向量 = [身高, 体重, 年龄, 成绩] = [170, 60, 20, 92]。每个特征是向量的一个维度。

student = np.array([170, 60, 20, 92])  # 4维向量
print(student.shape)  # (4,)
②
矩阵（Matrix）= 整个数据集或模型参数

多个向量堆叠成的二维数组。整个数据集（1000个学生，每人4个特征）就是一个 1000×4 的矩阵。模型的参数（权重）也是矩阵。

X = np.random.randn(1000, 4)  # 1000行4列：1000个学生
W = np.random.randn(4, 1)     # 权重矩阵
y_pred = X @ W                # 矩阵乘法 → 1000×1 的预测结果
③
点积（Dot Product）= 衡量两向量的相似度

两个向量的点积 = 各对应元素相乘再求和。神经网络的每一层都是在做矩阵乘法（本质是对每对行列做点积）。

a = np.array([1, 2, 3])
b = np.array([4, 5, 6])
print(np.dot(a, b))  # 1×4 + 2×5 + 3×6 = 32
记住这个等式：神经网络的每一层 = 输入矩阵 × 权重矩阵 + 偏置。整个"学习"过程就是在反复调整权重矩阵，直到输出符合预期。
⑤

概率与统计基础

机器学习模型的输出本质上都是概率。理解概率，才能理解模型在"说什么"。

概念直白解释在 AI 中的角色
概率（Probability）某件事发生的可能性，0到1之间的数分类器输出"这张图是猫的概率 0.92"
条件概率 P(A|B)已知 B 发生，A 发生的概率P(垃圾邮件|含"免费")：见到"免费"时邮件是垃圾的概率
概率分布描述随机变量所有可能值的概率模型输出各类别的概率分布，选最大值作为预测
贝叶斯思维：为什么准确率 99% 的检测，阳性不等于 99% 患病？
某病患病率 0.1%，检测准确率 99%。你阳性了，实际患病概率是多少？

直觉说"99%"——贝叶斯算出来约 9%。原因：人群里大多数人健康，"阳性"中大多数是误报。

这就是为什么 AI 在稀有事件（欺诈检测、罕见病诊断）上，即使准确率很高，实际精确率仍可能很低——需要结合基础发生率来解读。
▸ 常用统计量（数据探索必知）
data = np.array([12, 15, 14, 18, 11, 14, 15, 16, 13, 14])

print(f"均值:   {np.mean(data):.1f}")    # 14.2  中心趋势
print(f"中位数: {np.median(data):.1f}") # 14.0  不受异常值影响
print(f"标准差: {np.std(data):.2f}")    # 1.94  数据的分散程度
print(f"最大值: {np.max(data)}")
print(f"最小值: {np.min(data)}")

微积分：导数与梯度

你不需要手算积分，但必须理解导数是什么、梯度下降用导数做了什么——这是理解"模型如何学习"的最后一块拼图。

①
导数（Derivative）= 函数在某点的斜率

导数告诉我们：把输入稍微增大一点，输出会怎么变？正导数 = 输出随输入增大；负导数 = 输出随输入减小；导数为 0 = 当前是极值点（最高或最低）。

类比：爬山时感受脚下地面的坡度，就是在感知"导数"。坡度告诉你往哪走会上坡，往哪走会下坡。
②
梯度（Gradient）= 多维函数的"方向导数"

当函数有多个输入（比如模型有几百万个参数），需要知道调哪个参数、往哪个方向调才能让损失下降最快。梯度 = 损失函数对每个参数的偏导数组成的向量，指向损失增大最快的方向。

③
梯度下降（Gradient Descent）= 反方向走，让损失减小

更新规则：参数 = 参数 - 学习率 × 梯度
学习率控制每步走多大。太大会震荡跳过最低点；太小收敛太慢。

# 梯度下降最小化 f(x) = x² 的简单示例
x = 10.0
lr = 0.1        # 学习率
for i in range(20):
    grad = 2 * x    # f(x)=x² 的导数是 2x
    x = x - lr * grad
print(f"最终 x ≈ {x:.6f}")  # 接近 0（最小值点）
④
链式法则（Chain Rule）= 反向传播的数学基础

神经网络是多层函数嵌套。反向传播用链式法则，从输出层往输入层方向逐层计算每个参数对损失的偏导数。PyTorch/TensorFlow 的 autograd 自动帮你计算，但理解原理让你在调参时不再盲目。

实用底线：你要能理解"学习率太大导致训练震荡"、"梯度消失让深层网络难训练"这类诊断。不需要手算，但要知道含义。

实践：数据探索完整流程

以下是一个完整的数据探索脚本，涵盖本章所有工具，可直接在 Jupyter Notebook 中运行。

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

# ① 生成模拟学生数据
np.random.seed(42)
n = 200
df = pd.DataFrame({
    "study_hours": np.random.uniform(1, 10, n),
    "sleep_hours": np.random.uniform(4, 9,  n),
    "score":       np.random.randint(40, 100, n)
})

# ② 基本统计
print("== 数据概览 ==")
print(df.describe())

# ③ 高分学生分析
high_scorers = df[df["score"] >= 85]
print(f"\n高分学生数量: {len(high_scorers)}")
print(f"高分学生平均学习时长: {high_scorers['study_hours'].mean():.1f} 小时")

# ④ 相关性（学习时长与分数是否相关？）
corr = df["study_hours"].corr(df["score"])
print(f"\n学习时长与分数的相关系数: {corr:.3f}")
# 接近 1 = 强正相关；接近 -1 = 强负相关；接近 0 = 无关

# ⑤ 可视化：散点图
plt.figure(figsize=(8, 4))
plt.scatter(df["study_hours"], df["score"], alpha=0.5, color="teal")
plt.xlabel("学习时长（小时）")
plt.ylabel("考试分数")
plt.title("学习时长 vs 考试分数")
plt.tight_layout()
plt.savefig("scatter.png")
print("图表已保存为 scatter.png")

词汇表

向量（Vector）
一维有序数字数组，在机器学习中用于表示单个样本的所有特征。例如一条房价数据 [面积, 房间数, 楼层] 是一个 3 维向量。
矩阵（Matrix）
二维数字数组。整个数据集（多个样本）构成矩阵；神经网络的权重参数也以矩阵形式存储和计算。
点积（Dot Product）
两个向量对应元素相乘后求和，衡量两向量的"相似度"。神经网络每个神经元的计算本质上都是点积加激活函数。
导数（Derivative）
函数在某点的斜率，描述输入微小变化时输出的变化方向和大小。是梯度下降的数学基础。
梯度（Gradient）
多变量函数对每个变量的偏导数组成的向量，指向函数增大最快的方向。梯度的反方向是损失减小最快的方向。
梯度下降（Gradient Descent）
通过反复沿梯度反方向微调参数来最小化损失函数的优化算法，是训练神经网络的核心机制。
学习率（Learning Rate）
梯度下降每步更新的步长大小，是最重要的超参数之一。太大震荡，太小收敛慢。
条件概率（Conditional Probability）
在已知某事件发生的前提下，另一事件发生的概率，记作 P(A|B)。分类模型输出的正是条件概率。
DataFrame
Pandas 的核心数据结构，类似 Excel 表格，有行列标签，是 Python 数据分析和 ML 数据预处理的标准格式。
广播（Broadcasting）
NumPy 允许不同形状数组进行运算的机制。例如对整列数据统一加减乘除，无需写循环，极大简化矩阵运算代码。
