本节定位

这是三门选修中最轻量的一章——它不重新讲一遍编程或数学，而是帮你搞清楚"你需要哪个子集，以及这个子集在 ML 里用在哪里"。大多数学习资源的链接已经在 ch0 前置导图里；本章只是补充语境：这个技能需要掌握到什么程度，ML 里哪个环节会用到它。

目标读者：刚点进"选修 21"、正在问"我需要学完整的 Python 吗？所有线性代数都要会吗？"的人。答案是：只需要一个子集，而且这个子集取决于你走应用路线（ch1–ch8）还是训练路线（ch22–ch23）。
①

前置清单：你需要哪个子集

1
Python（应用层子集）
需要到什么程度：能写函数、列表、字典、循环、文件读写、环境变量。
ML 里用在哪：数据预处理、调用 sklearn/torch API、写训练脚本。
资源：廖雪峰 Python 和 鱼C工作室（主链接已在 ch0 前置导图）
2
NumPy + Pandas
需要到什么程度：能创建数组/DataFrame，会切片、聚合、处理缺失值。
ML 里用在哪：特征矩阵 X、标签向量 y、数据预处理。
资源：NumPy Quickstart、Pandas Getting Started
3
线性代数（向量/矩阵）
需要到什么程度：理解向量点积、矩阵乘法的几何含义，能看懂形状记号 (m×n)。
ML 里用在哪：数据集表示、神经网络每层计算。
资源：3Blue1Brown 线性代数系列（英文+中字），B站官方空间 B站 3Blue1Brown
4
微积分（导数/梯度）
需要到什么程度：理解导数=斜率、梯度=方向导数、链式法则的直觉含义；不需要手算积分。
ML 里用在哪：反向传播、理解"学习率太大为什么会震荡"。
资源：3Blue1Brown 微积分系列
5
概率统计
需要到什么程度：理解均值/方差、条件概率、概率分布的含义。
ML 里用在哪：模型输出解读（分类器输出的是概率）、贝叶斯思维（为什么准确率99%不代表真的好）。
资源：可汗学院 统计与概率（中文）
路线差异：应用路线（ch1–ch8）只需 Python 子集；训练路线（ch22–ch23）额外需要线性代数、微积分、NumPy，概率统计要求更深。

新手扫雷（轻量）

3Blue1Brown 和可汗学院本身已经很友好，这里的"地雷"比较轻——主要是概念误区而非难度。

①
"学多深才算够"的困惑

不需要精通，理解直觉 + 会用代码验证就行。3Blue1Brown 的系列每集 15 分钟，看完有直觉就够了，不用刷题。衡量标准：能看懂 sklearn/PyTorch 文档里出现的公式符号，能大致解释"为什么这样做"。

②
为什么线代/微积分先看视频再碰代码

视频建直觉，NumPy/PyTorch 代码验证计算，反过来的顺序会让你陷入符号迷宫。推荐路径：先看 3B1B 系列建立几何感，再打开 NumPy 验证矩阵乘法的结果，最后才去看公式推导。

③
"向量化"这个词

NumPy 文档和 ML 课里经常说"向量化运算"，意思是：不要用 Python for 循环逐个处理数字，而是把整个数组交给 NumPy 一次性算。背后是 C 实现的矩阵运算，快 100 倍。新手第一次看到这个词常常懵——记住：凡是看到 np.dot()、@、np.sum(axis=...)，都是向量化写法，比手写循环快得多。
