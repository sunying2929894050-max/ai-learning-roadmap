Chapter 06
工具调用与 Agent

让大模型使用工具（搜索、代码执行、API 调用），理解 Agent 的规划-执行-观测循环。

⑥

AI Agent：让大模型自主完成多步骤任务

传统 AI：输入 → 模型 → 输出（一次性）。Agent：给模型一套工具，让它自己决定调用哪些工具、按什么顺序，完成复杂任务。

类比：AI 助理 vs AI 员工
传统 RAG/聊天机器人像"AI 助理"——你每次说一件事，它做一件事。Agent 像"AI 员工"——你说"帮我调研竞品并写报告"，它自己去搜索网页、整理信息、分析对比、最后写出报告。中间所有步骤它自己决定。
①
工具（Tools）

给 Agent 配备可调用的工具：搜索引擎、代码执行器、数据库查询、发送邮件、文件读写...每个工具有明确的输入输出定义。

②
规划（Planning）

Agent 收到任务后，先分解步骤，判断需要用哪些工具、按什么顺序。

③
执行 + 观察 + 调整（Act-Observe-Adjust 循环）

调用工具 → 观察结果 → 根据结果决定下一步 → 直到任务完成。

import anthropic

client = anthropic.Anthropic()

# 定义工具
tools = [
    {
        "name": "search_web",
        "description": "在互联网上搜索信息",
        "input_schema": {
            "type": "object",
            "properties": {
                "query": {"type": "string", "description": "搜索关键词"}
            },
            "required": ["query"]
        }
    },
    {
        "name": "calculate",
        "description": "执行数学计算",
        "input_schema": {
            "type": "object",
            "properties": {
                "expression": {"type": "string", "description": "数学表达式，如 '2 + 3 * 4'"}
            },
            "required": ["expression"]
        }
    }
]

# Agent 会自动决定调用哪个工具
response = client.messages.create(
    model="claude-opus-4-8",
    max_tokens=1024,
    tools=tools,
    messages=[{"role": "user", "content": "2024年中国 GDP 是多少？换算成美元大约是多少？"}]
)

# 检查是否调用了工具
if response.stop_reason == "tool_use":
    tool_call = response.content[-1]
    print(f"Agent 决定调用工具: {tool_call.name}")
    print(f"工具参数: {tool_call.input}")
Agent 的边界：Agent 越强大，风险越高。在生产环境中，工具调用权限要严格控制（Agent 不应该有删除数据库的权限），敏感操作需要人工审批，避免失控。
