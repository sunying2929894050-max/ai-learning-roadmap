RAG：让模型用你的私有知识

构建检索增强生成（RAG）系统，让大模型在本地知识库上回答问题，无需微调。

③

RAG：让大模型回答你的私有知识库

大模型只知道训练数据截止前的知识，不知道你公司的内部文档、最新数据、私有资料。RAG（检索增强生成）解决这个问题。

①
建立向量数据库

把你的文档（PDF、Word、网页）切分成小段（chunk），用"嵌入模型（Embedding Model）"把每段文字转换成向量，存入向量数据库（如 Chroma、Pinecone）。

嵌入向量：把文字的语义压缩成一串数字（如 1536维向量）。语义相近的文字，向量也相近——这是"语义搜索"的基础。
②
用户提问时，语义检索相关文档

把用户的问题也转成向量，在数据库中找最相似的几段文档（余弦相似度）。

③
把检索到的文档塞入提示词，让大模型回答

把检索到的相关文档片段作为上下文，连同用户问题一起发给大模型，让模型"参考这些资料"回答。

from langchain.vectorstores import Chroma
from langchain.embeddings import OpenAIEmbeddings
from langchain.text_splitter import RecursiveCharacterTextSplitter

# ① 切分文档
with open("company_handbook.txt") as f:
    text = f.read()

splitter = RecursiveCharacterTextSplitter(chunk_size=500, chunk_overlap=50)
chunks = splitter.split_text(text)

# ② 建立向量数据库
db = Chroma.from_texts(chunks, OpenAIEmbeddings())

# ③ 检索 + 生成
def rag_answer(question):
    # 检索最相关的 3 段文档
    relevant_docs = db.similarity_search(question, k=3)
    context = "\n\n".join([doc.page_content for doc in relevant_docs])

    prompt = f"""请根据以下公司手册内容回答问题。如果手册中没有相关信息，请明确说明。

相关内容：
{context}

问题：{question}"""

类比：开卷考试
RAG 就像把闭卷考试改成开卷——大模型考试前（推理时）可以翻阅你指定的资料书（知识库），然后综合作答。它的优势是能引用你的私有、最新的知识；局限是"资料书"里没有的内容它仍然不知道。
